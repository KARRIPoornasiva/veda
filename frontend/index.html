Official Guidelines

Challenge Rules & Parameters

👥

Team Size: 1 or 2

Each team can consist of either a single solo student or a collaborative pair of 2 students from any computing branch.

💳

Registration Fee

The official entry fee is ₹200 per Team. Full access to Lab 1 & 2 infrastructure and high-speed network provided.

🎯

2 Rounds

Round 1 (AI Agent Development) filters top contenders into Round 2 (Advanced AI Agent Challenge) for the final grand prize.

⏱️

3 Hours Per Round

Each sprint provides strictly 3hours to develop, integrate tools, test reasoning loops, and prepare a live demonstration.

✅

Permitted Technologies & Deliverables

  • ✓ Agent Frameworks: LangChain, LlamaIndex, AutoGen, CrewAI, Haystack, Semantic Kernel, or custom agent loops.
  • ✓ Models & APIs: Google Gemini API, OpenAI GPT, Anthropic Claude, Groq, HuggingFace, or local open weights.
  • ✓ Databases & RAG: ChromaDB, FAISS, Pinecone, Qdrant, SQLite, PostgreSQL, or knowledge graphs.
  • ✓ Autonomous Tools: Web search engines, custom REST APIs, code execution sandboxes, calculators, and file parsers.
  • ✓ Demonstrable Prototype: Must run live before the judging panel. Slides alone without execution will receive 0 demo score.
⚠️

Strict Regulations & Disqualifications

  • ✕ No Basic Chatbots: Standard LLM wrapper prompt UIs with no tool use, memory, or action loops are strictly disallowed.
  • ✕ No Pre-Built Turnkey Apps: Cloned boilerplate SaaS templates without original agentic architecture will be disqualified.
  • ✕ Hard Time Limit: Code freeze takes place exactly after 2 hours. Late repository pushes will not be evaluated.
  • ✕ Live Verifiability: Every API call, tool execution step, and retrieved context must be explainable during interrogation.
🛑

Official Rule Reminder: Basic Chatbots are Not Allowed!

Your agent must demonstrate at least two autonomous capabilities: dynamic tool/API invocation, memory state tracking, multi-hop RAG retrieval, or closed-loop self-correction.

Judging Rubric

Evaluation Criteria & Readiness Calculator

Understand how your AI Agent will be scored and simulate your potential ranking in real time.

🤖 Autonomy & Dynamic Tool Calling 25% Weight

Agent independently decides when and how to call external tools (APIs, search, DB query, code execution) without hardcoded branching.

💡 Problem Relevance & Innovation 25% Weight

Originality of the agentic solution, depth of domain understanding, and effective mitigation of target pain points.

🧠 Robustness, Memory & RAG Grounding 20% Weight

Handling noisy inputs, prevention of hallucinations through verified context retrieval, and multi-turn state retention.

⚡ Live Working Demonstration 20% Weight

Flawless execution during live judging test queries with transparent reasoning steps and real-time output delivery.

📐 Architecture & Code Hygiene 10% Weight

Clean modular code structure, clear separation of tools and prompts, readable documentation, and Git discipline.
